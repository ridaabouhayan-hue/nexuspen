# NexusPen

Lichtgewicht tekenprogramma over je scherm, gemaakt voor Nexus of Language.

- **Downloaden:** kijk bij Releases en kies `NexusPen-Setup.exe`.
- **Afspraken en ontwerp:** `BOUWPLAN.md` en `docs/ontwerp/`.
- **Werken met Claude Code:** lees eerst `CLAUDE.md`.
- **Zelf bouwen op Windows:** `powershell -ExecutionPolicy Bypass -File build\build.ps1`
